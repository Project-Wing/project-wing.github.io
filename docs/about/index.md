# 关于 Wing

Project Wing 是一个面向音乐爱好者社群的开源建站项目。

名字来源于司南，项目本身不绑定具体歌手。部署者可以配置站点名称与人物资料，整理不同音乐人的作品、影像及活动内容。

## 参与项目

访问 [Project Wing GitHub 组织](https://github.com/Project-Wing)，查看源码、提交问题或参与贡献。
