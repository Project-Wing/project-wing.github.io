# 开始之前

Wing 的完整站点由用户端、管理端、后端及数据库等服务共同组成。此仓库仅构建项目介绍网站与文档，不包含可直接运行的完整 Wing 实例。

## 选择配套版本

部署前应确认用户端、管理端、后端和数据库资源属于配套版本，并分别阅读对应仓库的 README 与发布说明。

Next 与旧版的环境要求、配置项及数据库结构存在差异，不应混用旧版初始化脚本和新版本服务。

## 准备站点资料

- 站点名称与介绍。
- 需要展示的音乐人资料。
- 作品、影像、演出等内容。
- 拥有使用权限的图片与其他素材。

## 部署文档状态

Next 的具体环境版本、部署命令与配置示例仍待在此站整理。请以相应源码仓库的当前说明为准。

详细教程补齐前，请通过 [GitHub 组织](https://github.com/Project-Wing)查阅各组件当前的 README 与发布说明。
