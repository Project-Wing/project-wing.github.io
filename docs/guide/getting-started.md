# 开始之前
## Wing有什么

Wing 的完整站点由用户端`wing-ui-user`、管理端`wing-ui-mgmt`、核心`wing-core`及数据库四个组件共同组成。

Wing 的运行需要Java运行环境，Nginx服务器和PostgreSQL，在环境准备栏目介绍了如何在主流操作系统安装这些软件。

## 选择配套版本

请确保您使用的四个组件均为最新版本。

## 环境依赖概述

### 硬件与系统环境

（强烈建议直接购买云服务器）

- 一台64位计算机（X64或ARM64）
- 处理器频率>=1.8Ghz
- 处理器核心数>=2
- 运行内存（RAM）容量>=2GB
- 可用磁盘空间>=40GB
- Windows 10，Windows11，Windows Server 2022及以上版本，或Debian，Ubuntu，ArchOS，OpenSUSE等主流64位Linux操作系统。

**MacOS未经测试，不保证可用**

### 网络环境

如果您要让所有人访问您的网站，您需要一个公网IP地址或固定IP地址，一般来说在您购买云服务器时供应商会告知您，如果您要使用自有硬件构建，您可能需要通过内网穿透等方式来实现公开访问。

### 软件环境

Wing的运行需要依赖下列组件。

|名称|版本|
|---|---|
|Java|>=21|
|PostgreSQL|>=18|
|Nginx|>=1.20|
|Redis|>=6.0|

编译需要以下组件。

|名称|版本|
|---|---|
|Java|>=21|
|Maven|>=3.7|
|Node.js|>=22|


**编译和运行可以是同一台计算机，也可以不是，请务必注意！**


### 访问

浏览器需要满足：

- Chromium（Google Chrome，Microsoft Edge，Android System Webview）：>=100
- FireFox: >=80

使用太旧的浏览器可能会遇到问题。


- **不支持Internet Explorer，请尽快迁移到Microsoft Edge获取安全连续的体验。**
- **不建议在社交软件（QQ，微信，小红书，抖音等）、夸克，360，UC，百度，搜狗等浏览器、或小米，红米，OPPO，VIVO，IQOO，华为，荣耀，国行联想，国行三星等手机自带浏览器中访问您部署的网站，可能会导致不必要的隐私问题。**

## 准备站点资料

准备下列材料来开始填写你的网站内容吧。

- 站点名称与介绍。
- 需要展示的音乐人资料（昵称，简介，账户等）。
- 作品、影像、演出等内容。
- 拥有使用权限的图片与其他素材。
