# 认识 Wing

Project Wing 是面向音乐爱好者社群的开源 Wiki 建站项目，用于整理歌曲、影像与演出活动等内容。

Wing 的名字来源于司南。项目本身不绑定任何歌手；具体站点的名称、人物资料和内容由部署者配置与维护。

## 项目组成

| 组件 | 作用 |
| --- | --- |
| 用户端 | 面向访客展示资料、作品与活动 |
| 管理端 | 面向维护者管理站点内容与配置 |
| 后端 | 提供业务接口、权限与数据服务 |
| 数据库资源 | 保存和初始化业务数据 |

源码入口：[Project Wing GitHub 组织](https://github.com/Project-Wing)。
